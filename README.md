# javascript-lotto-precourse

## 로또

간단한 로또 발매기를 구현하는 미션입니다. 사용자가 구매 금액을 입력하면 해당 금액만큼 로또를 발행하고, 당첨 번호와 보너스 번호를 입력받아 당첨 내역과 수익률을 계산하여 출력합니다.

## 기능 목록

### 1. 로또 구입 금액 입력
- 사용자로부터 로또 구입 금액을 입력받는다.
- 입력 형식: 정수 (예: `8000`, `14000`)
- 프롬프트: "구입금액을 입력해 주세요."

### 2. 로또 구입 금액 검증
- 1,000원 단위로 나누어 떨어져야 한다.
- 양수여야 한다.
- 숫자 형식이어야 한다.

**예외 상황:**
- 1,000원 단위가 아닌 경우: `"[ERROR] 로또 구입 금액은 1,000원 단위로 입력해야 합니다."`
- 숫자가 아닌 경우: `"[ERROR] 로또 구입 금액은 숫자여야 합니다."`
- 양수가 아닌 경우: `"[ERROR] 로또 구입 금액은 양수여야 합니다."`

### 3. 로또 발행
- 구입 금액에 따라 발행할 로또 수량을 계산한다. (구입 금액 / 1,000원)
- Random API를 사용하여 각 로또마다 중복되지 않는 6개의 숫자를 생성한다. (1~45 범위)
- 생성된 로또 번호는 오름차순으로 정렬하여 저장한다.

### 4. 발행한 로또 출력
- 발행한 로또 수량을 출력한다.
- 각 로또 번호를 오름차순으로 출력한다.
- 출력 형식:
  ```
  8개를 구매했습니다.
  [8, 21, 23, 41, 42, 43]
  [3, 5, 11, 16, 32, 38]
  ...
  ```

### 5. 당첨 번호 입력
- 당첨 번호 6개를 쉼표로 구분하여 입력받는다.
- 입력 형식: 쉼표로 구분된 정수 (예: `1,2,3,4,5,6`)
- 프롬프트: "당첨 번호를 입력해 주세요."

### 6. 당첨 번호 검증
- 정확히 6개의 숫자여야 한다.
- 각 숫자가 1 이상 45 이하여야 한다.
- 중복된 숫자가 없어야 한다.

**예외 상황:**
- 6개가 아닌 경우: `"[ERROR] 로또 번호는 6개여야 합니다."`
- 1~45 범위를 벗어난 경우: `"[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다."`
- 중복이 있는 경우: `"[ERROR] 로또 번호에 중복된 숫자가 있습니다."`

### 7. 보너스 번호 입력
- 보너스 번호 1개를 입력받는다.
- 입력 형식: 정수 (예: `7`)
- 프롬프트: "보너스 번호를 입력해 주세요."

### 8. 보너스 번호 검증
- 1 이상 45 이하여야 한다.
- 당첨 번호와 중복되지 않아야 한다.

**예외 상황:**
- 1~45 범위를 벗어난 경우: `"[ERROR] 보너스 번호는 1부터 45 사이의 숫자여야 합니다."`
- 당첨 번호와 중복되는 경우: `"[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다."`

### 9. 당첨 결과 계산
- 각 로또 번호와 당첨 번호를 비교하여 일치하는 개수를 계산한다.
- 보너스 번호 포함 여부를 확인한다.
- 등수를 판정한다.
  - **1등**: 6개 일치 → 2,000,000,000원
  - **2등**: 5개 일치 + 보너스 일치 → 30,000,000원
  - **3등**: 5개 일치 → 1,500,000원
  - **4등**: 4개 일치 → 50,000원
  - **5등**: 3개 일치 → 5,000원
  - **꽝**: 2개 이하 일치 → 0원

### 10. 당첨 통계 계산
- 발행한 모든 로또에 대한 등수별 당첨 개수를 계산한다.
- 총 당첨 금액을 계산한다.

### 11. 수익률 계산
- 수익률 = (총 당첨 금액 / 구입 금액) × 100
- 소수점 둘째 자리에서 반올림한다.

### 12. 당첨 통계 출력
- 당첨 통계 헤더를 출력한다.
- 등수별 당첨 내역을 출력한다.
- 총 수익률을 출력한다.
- 출력 형식:
  ```
  당첨 통계
  ---
  3개 일치 (5,000원) - 1개
  4개 일치 (50,000원) - 0개
  5개 일치 (1,500,000원) - 0개
  5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
  6개 일치 (2,000,000,000원) - 0개
  총 수익률은 62.5%입니다.
  ```

### 13. 예외 처리 및 재입력
- 모든 검증 실패 시 "[ERROR]"로 시작하는 메시지를 출력한다.
- 예외 발생 시 해당 입력부터 다시 입력을 받는다.

## 예외 처리

모든 예외 상황은 `[ERROR]`로 시작하는 메시지를 출력하고, 해당 입력부터 다시 입력을 받아야 합니다.

### 예외 상황 목록

1. **로또 구입 금액이 1,000원 단위가 아닌 경우**
   - 메시지: `"[ERROR] 로또 구입 금액은 1,000원 단위로 입력해야 합니다."`

2. **로또 구입 금액이 숫자가 아닌 경우**
   - 메시지: `"[ERROR] 로또 구입 금액은 숫자여야 합니다."`

3. **로또 구입 금액이 양수가 아닌 경우**
   - 메시지: `"[ERROR] 로또 구입 금액은 양수여야 합니다."`

4. **로또 번호가 6개가 아닌 경우**
   - 메시지: `"[ERROR] 로또 번호는 6개여야 합니다."`

5. **로또 번호가 1~45 범위를 벗어난 경우**
   - 메시지: `"[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다."`

6. **로또 번호에 중복이 있는 경우**
   - 메시지: `"[ERROR] 로또 번호에 중복된 숫자가 있습니다."`

7. **보너스 번호가 1~45 범위를 벗어난 경우**
   - 메시지: `"[ERROR] 보너스 번호는 1부터 45 사이의 숫자여야 합니다."`

8. **보너스 번호가 당첨 번호와 중복되는 경우**
   - 메시지: `"[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다."`

### 예외 처리 흐름

```
사용자 입력
  ↓
검증 로직 실행
  ↓
[검증 실패] → [ERROR] 메시지 출력 → 해당 입력 재요청
  ↓
[검증 성공] → 다음 단계 진행
